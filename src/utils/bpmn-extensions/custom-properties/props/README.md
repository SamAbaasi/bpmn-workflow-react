# sendTaskProps

In this file, the properties of the property panel are defined

## Functions

- **addDataSender(props: any):**
  This function adds the sender mail property for email in the sender group in the property panel.

- **addUserReciver(props: any):**
  This function adds the receiver User property for email in the reciver group in the property panel.

- **addGroupReciver(props: any):**
  This function adds the receiver Group property for email in the reciver group in the property panel.

- **addSubjectCompose(props: any):**
  This function adds the compose subject property for email in the compose group in the property panel.

- **addPyClassStartExecution(props: any):**
  This function adds the selectbox for choose python class in the start execution listener group in the property panel.

- **addPyClassEndExecution(props: any):**
  This function adds the selectbox for choose python class in the end execution listener group in the property panel.

- **addFormName(props: any):**
  This function adds the selectbox for choose form in the form group in the property panel.

- **addFormActivity(props: any):**
  This function adds the selectbox for choose activity in the form group in the property panel.

- **messageType(props: any):**
  This function adds the selectbox for choose type of message in the message type group in the property panel.

- **addGroupReciverForSMS(props: any):**
  This function adds the receiver Group property for SMS in the SMS configuration group in the property panel.

- **addUserReciverForSMS(props: any):**
  This function adds the receiver User property for SMS in the SMS configuration group in the property panel.

- **addNumberReciverForSMS(props: any):**
  This function adds the receiver number property for SMS in the SMS configuration group in the property panel.

- **addMessageTextSMS(props: any):**
  This function adds the message text property for SMS in the SMS configuration group in the property panel.

- **getTextElement(props: any):**
  This function create text box.

- **getTextAreaEntry(props: any):**
  This function create texterea.

- **getSelectbox(props: any):**
  This function create select box.
